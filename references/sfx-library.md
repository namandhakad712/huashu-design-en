## Usage Guidelines

### Volume Recommendations (from the dual-track system in apple-gallery-showcase.md)
- **SFX main track**: `1.0` (no attenuation)
- **BGM background track**: `0.4 ~ 0.5` (SFX cuts through clearly)
- **Multiple SFX stacked**: use `amix=inputs=N:duration=longest:normalize=0` to preserve the dynamic range

### ffmpeg Stitching Templates
```bash
# Align a single SFX to a time point:
ffmpeg -i video.mp4 -itsoffset 2.5 -i sfx/ui/click.mp3 \
  -filter_complex "[0:a][1:a]amix=inputs=2:duration=longest:normalize=0[a]" \
  -map 0:v -map "[a]" output.mp4

# Multiple SFX + BGM:
ffmpeg -i video.mp4 \
  -itsoffset 1.0 -i sfx/transition/whoosh-fast.mp3 \
  -itsoffset 1.6 -i sfx/impact/logo-reveal-v2.mp3 \
  -i bgm.mp3 \
  -filter_complex "[3:a]volume=0.4[bgm];[0:a][1:a][2:a][bgm]amix=inputs=4:normalize=0[a]" \
  -map 0:v -map "[a]" output.mp4
```

### Selection Decision Tree
1. **Tactile actions** (typing / clicking / swiping) → `keyboard/` or `ui/`
2. **Element enter/exit** → `transition/`
3. **Container-layer operations** (cards / modals) → `container/`
4. **State feedback** (success / failure / notifications) → `feedback/`
5. **Progress / the passage of time** → `progress/`
6. **Brand landings / key moments** → `impact/`
7. **AI magic / transformations** → `magic/`
8. **Command line / code demos** → `terminal/`

### Avoid Sound Stacking
- Max 2 SFX playing at the same time point
- You can have 3 once BGM drops below 0.3
- Clear other SFX for brand impacts (leave a 0.2s gap before the landing)

## Prompt Writing Principles (for Reuse)

Reference style: `apple keynote, tight, minimal, no reverb unless ambient, crisp, elegant`

**Three elements of a good prompt**:
1. **Physical description of the sound**: what object, what action ("mechanical keyboard single key press")
2. **Texture / style qualifiers**: apple-style / ios-style / cinematic / retro
3. **Exclusions** (negative examples): no reverb / clean studio / minimal

❌ "click sound"
✅ "crisp ui button click, clean modern interface sound, apple-style, high pitched"

❌ "magic"
✅ "bright twinkling stars sound, high pitched glittery chime, fairy dust"
